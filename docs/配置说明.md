# 绝区零体力显示屏 · 配置说明

这是一套跑在 ESP32 上的小装置：插上电、连上 Wi-Fi，屏幕就会显示你自己账号的：

- 电量 / 满电量、回满还要多久
- 今日活跃度
- 录像带店状态、刮刮卡状态
- 下一次版本更新的倒计时和具体时间

数据是从米游社的绝区零“实时便笺”接口读的，不依赖游戏在线，手机电脑都不用开着。

> 整个包里**不含任何别人的账号信息**，Wi-Fi、米游社凭据、游戏 UID 都要你自己填。
> 所有要填的东西都在 `esp32_zzz_display/config.h` 这一个文件里。

## 一、准备清单

### 硬件

| 物品 | 说明 |
|---|---|
| ESP32-WROOM-32 开发板 | 任意 ESP32 Dev Module 都行 |
| 2.4 寸 ILI9341 SPI 液晶屏 | 240×320，8 根排针那种 |
| 杜邦线 | 母对母 / 母对公，看你的板子 |
| USB 数据线 | **必须能传数据**，只能充电的线会连不上电脑 |

### 软件

1. **Arduino IDE**（2.x 版本）
2. **ESP32 开发板支持**：
   - `文件 → 首选项`，“附加开发板管理器地址”里填：
     `https://espressif.github.io/arduino-esp32/package_esp32_index.json`
   - `工具 → 开发板 → 开发板管理器`，搜索 `esp32`，安装 `esp32 by Espressif Systems`
3. **两个库**：`工具 → 管理库`，分别搜索并安装
   - `TFT_eSPI`（作者 Bodmer）
   - `ArduinoJson`（作者 Benoit Blanchon）

## 二、接线

屏幕引脚比较少见的名字我都列出来了。按下面这张表接，一根都别错。

| 屏幕引脚 | 接到 ESP32 | 作用 |
|---|---|---|
| `VCC` | `3V3` | 供电，**先用 3.3V** |
| `GND` | `GND` | 必须和 ESP32 共地 |
| `SDA` / `SDI` / `MOSI` | `GPIO23` | SPI 数据 |
| `SCK` / `SCL` / `CLK` | `GPIO18` | SPI 时钟 |
| `CS` | `GPIO5` | 片选 |
| `DC` / `RS` / `A0` | `GPIO27` | 命令/数据选择 |
| `RESET` / `RST` | `GPIO14` | 复位 |
| `LED` / `BL` / `BCKL` | `GPIO21` | 背光 |
| `SDO` / `MISO` | `GPIO19` | 可选，不接也能显示 |

不用接的：`T_CS`、`T_IRQ`、`T_DIN`、`T_DO`、`T_CLK`（触摸），
`SD_CS`、`SD_MOSI`、`SD_MISO`、`SD_SCK`（SD 卡）。

所以最少 8 根线就能跑：`VCC`、`GND`、`MOSI`、`SCK`、`CS`、`DC`、`RESET`、`BL`。

**注意事项**

- `VCC` 先接 `3V3`。只有模块上明确带稳压芯片（比如 AMS1117）或者写着 5V 兼容时才能接 5V。
- 逻辑脚（`CS`/`DC`/`RST`/`MOSI`/`SCK`）**不要接 5V**，ESP32 是 3.3V 电平。
- 背光如果很亮、电流大，别长期直接从 GPIO 供电。

如果你接线和上面不一样，改完线之后必须同步改 `tft_setup.h` 里的 GPIO 编号，否则屏幕会白屏或花屏。

## 三、获取你自己的米游社凭据

这一步是唯一有点绕的地方，因为米游社的接口只认 **App 端登录产生的 `stoken`**，
网页版 Cookie 是不行的（会返回 `-100 请先登录`）。

你需要拿到三个值：`stuid`、`mid`、`stoken`。

### 方法 A：用扫码登录工具（推荐）

1. 打开 [mihoyo-stoken-login](https://github.com/gggssepgf/mihoyo-stoken-login)，
   在 Releases 里下载 `mihoyo-stoken-login-gui.exe`（Windows 单文件，不用装 Python）。
2. 双击运行，窗口里会出现一个二维码。
3. 打开手机上的**米游社 App** → 右上角扫一扫 → 扫描这个二维码 → 手机上确认登录。
4. 工具里会显示：

   ```text
   stuid=xxxxxxxx
   mid=xxxxxxxxxxxx_mhy
   stoken=v2_xxxxxxxx...
   ```

   把这三行记下来，等下填进 `config.h`。

### 方法 B：已经有现成的 stoken

如果你以前配过 MihoyoBBSTools 之类的米游社工具，里面的 `stoken`、`mid`、`stuid`
可以直接拿来用，不用重新扫。

### 顺便记下你的绝区零 UID

打开游戏 → `设置` → `账户` → 看 `UID`，是一串 9 位数字（例如 `123456789`）。
这个也要填进配置。

> 提醒：`stoken` 等同于你的登录凭证，等于把账号借给别人用，**不要发给任何人**，
> 也不要把填好的 `config.h` 发到群里或上传到网上。

## 四、填写 config.h

用文本编辑器打开 `esp32_zzz_display/config.h`，把每一项换成你自己的。

### 1. Wi-Fi

```cpp
constexpr char kWifiSsid[] = "你的WiFi名称";
constexpr char kWifiPassword[] = "你的WiFi密码";
```

- **必须是 2.4GHz 的 Wi-Fi**。ESP32 不支持 5GHz，如果你家路由器把 2.4G 和 5G 分成了
  两个不同的名字，请填 2.4G 那个名字。
- 如果填错，串口会一直打印“正在连接”，屏幕停在启动画面。

### 2. 校园网 / 酒店门户（家里用就留空）

```cpp
constexpr char kPortalHost[] = "";
constexpr char kPortalUsername[] = "";
constexpr char kPortalPassword[] = "";
```

家里 Wi-Fi 直接能上网，这三项**保持空字符串**，固件会自动跳过门户认证。

只有“连上 Wi-Fi 后还要用浏览器打开一个网页登录”的网络（校园网、部分酒店）才需要填。
本模块适配的是深澜（Srun）认证系统，填法：

```cpp
constexpr char kPortalHost[] = "net.你的学校.edu.cn";
constexpr char kPortalUsername[] = "你的账号";
constexpr char kPortalPassword[] = "你的密码";
```

不确定就别填，留空最安全。

### 3. 绝区零 UID

```cpp
constexpr char kZzzRoleId[] = "你的9位UID";
constexpr char kZzzServer[] = "prod_gf_cn";   // 国服固定，不要改
```

### 4. 米游社凭据

把第三节抄下来的值填进去：

```cpp
constexpr char kStuid[] = "你的stuid";
constexpr char kStoken[] = "你的stoken";
constexpr char kMid[] = "你的mid";
constexpr char kDeviceId[] = "";               // 留空，固件自动生成
```

下面这三项只有启用菲林月报才用得到，现在保持空着就行：

```cpp
constexpr char kLtokenV2[] = "";
constexpr char kCookieTokenV2[] = "";
constexpr char kDeviceFp[] = "";
```

最后一节“通用参数”不用动。

## 五、编译并上传

1. 用 Arduino IDE 打开 `esp32_zzz_display/esp32_zzz_display.ino`。
   （注意是打开这个文件夹里的 `.ino`，同目录的 `config.h`、`tft_setup.h`、
   `cjk_font.h`、`srun_portal.h` 会被自动带上。）
2. `工具 → 开发板` 选 **ESP32 Dev Module**。
3. `工具 → 端口` 选你的 ESP32 所在的 COM 口。
4. 点左上角的上传按钮（右箭头）。
5. 上传完成后打开 `工具 → 串口监视器`，**波特率选 115200**。

一切正常的话你会看到类似输出：

```text
=== 绝区零显示屏启动 ===
[网络] 正在连接 你的WiFi名称
[网络] 已连接 IP=192.168.1.23 信号=-55 dBm
[时间] 已同步 2026-10-14 15:00:54
[实时便笺] 电量=183/240 回满=5时41分(20488秒) 活跃度=0/400 录像带店=待结算 刮刮卡=未刮
[版本更新] 更新时间=2026-10-21 06:00 剩余=6天14时59分
```

如果串口监视器里中文是乱码，把串口监视器右下角的编码改成 `UTF-8`。

## 六、常见问题

**屏幕背光亮着，但什么都没有**

1. 检查 `CS`、`DC`、`RESET` 三根线是不是接错了。
2. 屏幕和 ESP32 必须共地（`GND` 要连）。
3. 花屏或闪屏：把 `tft_setup.h` 里的 `SPI_FREQUENCY` 从 `27000000` 改成 `20000000`。
4. 红蓝颜色反了：把 `tft_setup.h` 里的 `TFT_RGB_ORDER` 那行取消注释并改成 `TFT_RGB`。

**串口一直刷“正在连接”，连不上 Wi-Fi**

- 确认填的是 2.4GHz 的 Wi-Fi 名字，大小写要完全一致。
- 密码确认没打错。
- 路由器如果开了“AP 隔离”，可能连不上，先关掉试试。

**串口显示 `[实时便笺] 请求失败 retcode=-100`**

说明 `stoken` 不对或者已经失效。重新按第三节扫一次码，更新 `config.h` 里的
`kStoken` / `kStuid` / `kMid` 再上传。

**串口显示 `[实时便笺] 请求失败 retcode=-10035`**

米游社的风控。通常过一段时间会自己恢复；如果一直这样，用米游社 App 正常登录一次
并打开绝区零的“实时便笺”页面，再重新试。

**屏幕下半部分“更新日期”显示 `--`**

版本公告还没读到。这个数据 6 小时才刷新一次，第一次上电可能刚好没取到，重启一次即可。
如果长期读不到，把这行串口输出发出来：

```text
[版本更新] 状态=... 分块传输=...
[版本更新] 读取结束 共...字节 标记=...
```

## 七、改屏幕上的文字

屏幕上的汉字是预先生成的点阵字模，放在 `cjk_font.h`。
如果你改了界面上的中文，需要重新生成字模：

```bash
python tools/gen_cjk_font.py
```

然后跑一下检查脚本，确认没有缺字：

```bash
python tools/verify_cjk_coverage.py
```

输出 `missing (none)` 就说明字模齐全。缺字的话屏幕上会出现空心方块。

## 八、文件说明

| 文件 | 作用 |
|---|---|
| `esp32_zzz_display.ino` | 主程序 |
| `config.h` | **你要改的就是这个**：Wi-Fi、米游社凭据、UID |
